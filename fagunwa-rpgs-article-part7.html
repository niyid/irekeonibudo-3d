Overdue

Six Entries In, Not One Screenshot

Every previous part of this series proved its claims against diff and the commit log, because that's what code review checks. But a riddle pool being wisdom-gated and a riddle pool looking like anything at all are different claims, and this series never made the second one until now. These twenty images are that check — the Unity Editor's Play mode, a screenshot taken, the file copied to disk, nothing staged in between.

🗂️
Where these actually live

All twenty files were copied into ~/git/irekeonibudo-3d/screenshots/ in one pass — both kingdoms' captures deployed side by side in the same folder, ireke_* and ogbo_* prefixed so they sort apart. That's also where the images below are served from.

One Cast, Two Skins

Swift, Brute, Titan — Same Three Presets, Reflavored

CreatureAI.cs ships one script with three role presets — Swift (fast, fragile), Brute (slow, punishing), and Titan (towering) — rather than three duplicated files per story. What's on screen is the visible half of that architecture claim: two completely different bestiaries, built from the same three stat curves.

What's placeholder and what isn't

The seven custom character/creature models in each kingdom came out of a Tripo/Meshy prompt list (irekeonibudo-meshy_prompts.txt) — that's the smooth, sculpted cast you'll see below. The trees and mushrooms are Kenney/Poly Haven CC0 kit assets, low-poly on purpose, holding the place until a custom flora pass is worth the credits.

Ìjọba Omi — The Undersea Kingdom

Ìrèké Oníbùdó: Ten Shots From the Reef

A shipwrecked traveler swept into Arogidigba's undersea kingdom, guided through her trials by his dead mother's spirit — that's the book's actual premise, and it's the one SceneSetupWizard builds when you run Ireke Onibudo → Build Entire Universe. Coral-reef stand-ins instead of forest, a riverside hub instead of a village, the same three-preset cast wearing this story's names.

Conclusion

The Same Rule, Applied to Pixels This Time

Part VI's closing line was that the only source of truth is the diff — that a description of work drifts from the work itself unless someone checks the actual files every time. Screenshots are the same discipline turned on the render instead of the source: not a mood-boarded mockup of what Arogidigba's kingdom might look like, but ls -l and twenty files that were actually copied off an actual Play-mode session. The next entry that owes the series a compile check and a riddle UI still owes them. This one only owed proof that there was something on screen worth checking against — there is, and now it's on record.
